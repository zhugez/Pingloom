# Pingloom

Desktop pings and emotes placed through a radial gesture, independent of the game itself.

## Language

**Ping**:
A short-lived visual marker with an associated sound that expresses an intent such as danger or assistance.
_Avoid_: Notification

**Emote**:
A short-lived expressive image or animation with an optional associated sound.
_Avoid_: Ping, sticker

**Wheel**:
An eight-slice radial selection of pings or emotes, with a centre cancellation zone.
_Avoid_: Menu

**Trigger**:
The key held to begin a wheel gesture.
_Avoid_: Shortcut

**Gesture**:
A trigger-held pointer drag that chooses a wheel slice or cancels in the centre.

**Toggle shortcut**:
The key combination that pauses or resumes desktop gestures.
_Avoid_: Trigger

**Pause**:
A state in which ordinary input passes through and no desktop gesture is initiated.
